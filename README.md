# Budget App – Personal Budget Management & Analysis

## About the Project

This project is a Python-based budget management application designed to organize and track personal finances.

It uses Object-Oriented Programming (OOP) to manage different budget categories, record deposits and withdrawals, transfer funds between categories, and calculate available balances.

The project will also explore financial data analysis and visualization to better understand spending habits and budget distribution.

## Technologies Used

- **Python** – Core programming language
- **OOP** – Organizing budget categories and financial operations
- **Pandas** – Financial data processing and analysis
- **NumPy** – Numerical and statistical calculations
- **Matplotlib** – Financial data visualization

## Features

- Create different budget categories.
- Deposit money into categories.
- Withdraw money from categories.
- Check available balances.
- Transfer funds between categories.
- Track financial transactions.
- Display transaction history.
- Generate category-based spending summaries.

## Data Analysis (Planned)
